本次变化

EMP免疫

免疫EMP效果，不会因此陷入瘫痪。

  • 主武器参数调整

    基础伤害由 160 改为 130；开火间隔由 125 改为 13逻辑帧；射程由 3.5 改为 8格。

  • 主武器对不同护甲的效果调整

    对无甲步兵的伤害倍率：150% → 210%；对防弹衣步兵的伤害倍率：140% → 210%；对重甲步兵的伤害倍率：125% → 215%；其余倍率见关键对比。

  • 获得护盾

    获得 750 点护盾；继承本体护甲；每次回复 15%；破盾后可自动重建。

  • 精神控制免疫调整

    精神控制免疫能力由 默认 改为 启用。

  • 生命值调整

    耐久由 800 改为 1250。

  • 造价调整

    生产成本由 2000 改为 3000。

另外 4 项变化
  • 护甲类型调整

    受击时使用的护甲类型由 f_jet 改为 f_harb。

  • 科技等级调整

    建造资格由 10 改为 11。

  • 视野调整

    侦察范围由 7 改为 0。

  • 美术资源调整

    图标或模型引用发生变化；此项描述外观资源。

变化摘要

主武器参数调整：基础伤害由 160 改为 130；开火间隔由 125 改为 13逻辑帧；射程由 3.5 改为 8格。 主武器对不同护甲的效果调整：对无甲步兵的伤害倍率：150% → 210%；对防弹衣步兵的伤害倍率：140% → 210%；对重甲步兵的伤害倍率：125% → 215%；其余倍率见关键对比。
