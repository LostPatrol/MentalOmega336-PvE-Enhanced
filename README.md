# MentalOmega336-PvE-Enhanced

**心灵终结 3.3.6 PVE 增强版**，由 [LostPatrol](https://github.com/LostPatrol) 维护的非官方个人修改项目，围绕合作挑战、单位与科技解锁、平衡调整和玩法资料整理展开。

## 项目内容

本地项目以 Mental Omega 3.3.6 为基础，包含游戏规则与资源覆盖层、10 张挑战地图，以及单位图鉴、地图说明和科技树资料。它依赖原游戏和 Mental Omega，不是独立游戏或完整安装包。

## 当前公开范围

**本仓库目前仅发布项目说明、许可证分析和 Git 配置，不提供可安装的游戏修改包。** 游戏规则、地图、MIX 素材包、DLL 和现有 Wiki 尚未公开上传，待确认相关作者的发布授权后再决定分发范围。

游戏与模组请通过各自的官方渠道获取：[Mental Omega 官方网站](https://mentalomega.com/)。
